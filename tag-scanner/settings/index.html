Square Point of Sale

Deep-links into the Square Point of Sale app on this phone to charge the item's price. Only works on iOS/Android with the Square POS app installed — get your Application ID at developer.squareup.com/apps.

Use this for a solo vendor with just a phone and a Square Reader (the small card-swipe/tap dongle). A Reader has no Terminal API support of its own — it only works through Square's own POS app on the phone, which is exactly what this deep link opens.

Square Terminals

Register each paired Square Terminal here. When several people use the app at once, checkouts queue automatically and route to whichever terminal frees up next. Find each device id by pairing it (Square's device code flow) and calling Square's Devices API — it looks like "device:XXXXXXXXXXXXXXXX".

Use this for an organization with dedicated Square Terminal or Square Register hardware (standalone devices with their own screen). A single registered terminal works fine too — with only one, every checkout goes straight to it with no waiting, so this is safe to use even for just one device.

Venmo
